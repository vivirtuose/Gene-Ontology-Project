## Lectures prioritaires

Ordre de la liste « Lectures prioritaires » de l'analyse bibliographique (A, §7). Les cinq lectures recommandées par le sujet (S) en font toutes partie (marquées ★).

1. ★ **Good BM, Van Auken K, Hill DP, Mi H, Carbon S, Balhoff JP, Albou LP, Thomas PD, Mungall CJ, Blake JA, D'Eustachio P (2021).** Reactome and the Gene Ontology: digital convergence of data resources. *Bioinformatics* 37:3343–3348.
   DOI : [10.1093/bioinformatics/btab325](https://doi.org/10.1093/bioinformatics/btab325)
   *Pourquoi :* la convergence Reactome–GO (Pathways2GO, GO-CAM), point de départ factuel. Cité dans : S[8], A[12], D[9].

2. **Gillis J, Pavlidis P (2013).** Assessing identity, redundancy and confounds in Gene Ontology annotations over time. *Bioinformatics* 29:476–482.
   DOI : [10.1093/bioinformatics/bts727](https://doi.org/10.1093/bioinformatics/bts727)
   *Pourquoi :* le précédent le plus proche (confusion entre ressources par publications partagées). Cité dans : S[5], A[8], D[12].

3. ★ **Gaudet P, Dessimoz C (2017).** Gene Ontology: pitfalls, biases, and remedies. *Methods Mol. Biol.* 1446:189–205.
   DOI : [10.1007/978-1-4939-3743-1_14](https://doi.org/10.1007/978-1-4939-3743-1_14)
   *Pourquoi :* biais et bon usage des annotations GO. Cité dans : S[4], A[5], D[16].

4. ★ **Rhee SY, Wood V, Dolinski K, Draghici S (2008).** Use and misuse of the gene ontology annotations. *Nat. Rev. Genet.* 9:509–515.
   DOI : [10.1038/nrg2363](https://doi.org/10.1038/nrg2363)
   *Pourquoi :* bon et mauvais usage des codes de preuve. Cité dans : S[16], A[18], D[15].

5. **Gaudet P, Livstone MS, Lewis SE, Thomas PD (2011).** Phylogenetic-based propagation of functional annotations within the Gene Ontology consortium. *Brief. Bioinform.* 12:449–462.
   DOI : [10.1093/bib/bbr042](https://doi.org/10.1093/bib/bbr042)
   *Pourquoi :* annotations IBA sur les arbres PANTHER (catégorie C2). Cité dans : S[3], A[4], D[11].

6. ★ **Gable AL, Szklarczyk D, Lyon D, Matias Rodrigues JF, von Mering C (2022).** Systematic assessment of pathway databases, based on a diverse collection of user-submitted experiments. *Brief. Bioinform.* 23:bbac355.
   DOI : [10.1093/bib/bbac355](https://doi.org/10.1093/bib/bbac355)
   *Pourquoi :* comparaison de 11 systèmes d'annotation pour l'enrichissement. Cité dans : S[2], A[3], D[7].

7. ★ **Wijesooriya K, Jadaan SA, Perera KL, Kaur T, Ziemann M (2022).** Urgent need for consistent standards in functional enrichment analysis. *PLoS Comput. Biol.* 18:e1009935.
   DOI : [10.1371/journal.pcbi.1009935](https://doi.org/10.1371/journal.pcbi.1009935)
   *Pourquoi :* bonnes pratiques (univers de référence, correction multiple). Cité dans : S[21], A[24], D[23].

8. **Tomczak A, Mortensen JM, Winnenburg R, et al. (2018).** Interpretation of biological experiments changes with evolution of the Gene Ontology and its annotations. *Sci. Rep.* 8:5115.
   DOI : [10.1038/s41598-018-23395-2](https://doi.org/10.1038/s41598-018-23395-2)
   *Pourquoi :* effet des versions de GO sur l'interprétation. Cité dans : A[23], D[17].

9. **Hu M, Alkhairy S, Lee I, Pillich RT, Fong D, Smith K, Bachelder R, Ideker T, Pratt D (2025).** Evaluation of large language models for discovery of gene set function. *Nat. Methods* 22:82–91 (en ligne en 2024).
   DOI : [10.1038/s41592-024-02525-x](https://doi.org/10.1038/s41592-024-02525-x)
   *Pourquoi :* LLM et fonction des ensembles de gènes. Cité dans : A[14], D[18].

10. **Wang Z, Jin Q, Wei C-H, Tian S, Lai P-T, Zhu Q, Day C-P, Ross C, Leaman R, Lu Z (2025).** GeneAgent: self-verification language agent for gene-set analysis using domain databases. *Nat. Methods* 22:1677–1685.
    DOI : [10.1038/s41592-025-02748-6](https://doi.org/10.1038/s41592-025-02748-6)
    *Pourquoi :* LLM qui vérifie ses affirmations contre des bases curées, le travail le plus proche pour Q3. Cité dans : A[6], D[19].

## Corrections à reporter dans les PDF

Ces écarts entre les PDF et les notices Crossref ont été relevés pendant la vérification :

- **evoGO** : les PDF indiquent « [Auteurs Evotec, liste à vérifier] ». Auteurs selon Crossref : Strielkov I, Buinovskaja G, Uvarovskii A, Galatenko V.
- **GeneAgent** : les PDF indiquent « [NIH, 10 auteurs] ». Auteurs : Wang Z, Jin Q, Wei C-H, Tian S, Lai P-T, Zhu Q, Day C-P, Ross C, Leaman R, Lu Z. Pagination : *Nat. Methods* 22:1677–1685.
- **Hu et al.** : citée « 2024 » avec le DOI seul. La version imprimée est *Nat. Methods* 2025;22:82–91.
- **GO knowledgebase 2026** : citée « 54:D1779 ». Pages complètes D1779–D1792. Un erratum existe (gkag678).
- **Reactome** : les fichiers citent la mise à jour 2024. Une mise à jour plus récente existe, « The Reactome Knowledgebase 2026 », *Nucleic Acids Res.* 54:D673–D681, DOI [10.1093/nar/gkaf1223](https://doi.org/10.1093/nar/gkaf1223). Elle est à citer si la release utilisée correspond à cette version. Cette référence ne figure dans aucun des PDF.
